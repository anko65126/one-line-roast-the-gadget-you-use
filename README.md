One line for the 'One-Line Roast: The Gadget You Use Every Day' bounty, roasting the smart speaker on the kitchen counter: it hears a whisper from the next room but goes deaf when the alarm needs stopping — selective hearing, now with Wi-Fi. The program writes that single line to /output/entry.txt.

## Run it

```sh
python3 main.py
```
